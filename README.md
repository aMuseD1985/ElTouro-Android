# ElTouro-Android

Android-App von [ElTouro](https://eltouro.de) – „Finde deine Tour. Finde deine Herde.“
Capacitor-Hülle um die Web-App plus nativer Kern in Kotlin (Aufzeichnen und Navigieren mit ausgeschaltetem Display).
